## 复现

关闭正在运行的助手，使用已安装完整依赖的 Python：

```powershell
$env:PYTHONPATH = "$PWD\app"
python -m unittest discover -s tests -v
python tests/smoke_ui.py
python tests/verify_gpu.py
python scripts/setup_offline.py --downloads "你的下载文件夹" --check-only
python scripts/build_release.py
```

GPU 检查会播放少量公开测试文字；不会读取剪贴板。历史开发脚本可能输出报告到 `.local/`，不进入发布包。日常程序不生成此类报告。
