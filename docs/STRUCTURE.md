# 项目结构与部署边界

## 源码目录

- `app/reader_app.py`：应用生命周期、任务协调与用户操作。
- `app/reader_ui.py`：页面、组件样式和布局；不加载模型、不读写个人文件。
- `app/reader_core.py`：任务协调线程、流式生成、播放与导出调度；不直接加载显卡模型。
- `app/model_worker.py`：单个持久模型子进程、本机有界通信、取消、故障恢复和主程序退出联动回收。
- `app/audio_output.py`：独立管理线程拥有唯一音频流，通过 Windows 默认端点检测切换并有限重连。
- `app/win_native.py`、`hotkeys.py`、`startup.py`：Windows 集成和快捷键规则。
- `app/selection_uia.py`：复制失败后的辅助功能取字；匿名管道传递真实选区，独立隐藏进程有超时和取消保护，不读剪贴板或保存正文。
- `app/priority_hotkeys.py`：可选的线程内键盘接管；回调只匹配设定组合并投递操作，不执行复制、推理或文件操作。
- `app/mp3_export.py`、`tempo.py`：MP3 编码、磁盘错误检查与语速处理。
- `app/audio_gain.py`：播放与导出共用的音量/增益处理，超过 100% 时柔和限幅。
- `app/export_plan.py`：仅在内存中规划单文件/分章输出，文件名不使用原文，不保存续作状态。
- `app/runtime_errors.py`：固定错误类别与安全提示；不保存异常正文或路径。
- `app/export_estimate.py`：纯数值的文本分析、短样本选择和耗时范围；不访问模型、文件或设置。
- `app/ui_tooltip.py`：临时悬浮说明，不保存使用状态。
- `app/settings.py`、`privacy.py`：设置位置、迁移和应用自身的隐私边界。
- `assets/`：项目自制图标。
- `scripts/`：下载、离线安装及源码打包工具与固定清单。
- `tests/`：轻量测试、窗口布局检查及可选的显卡验证。
- `docs/`：结构和验证说明。

这种规模保持一层模块目录即可；没有为每个功能另建框架或多重服务层。

## 本机数据与兼容入口

- 默认下载内容在 `.downloads/`，包括模型、安装包和下载记录。
- 虚拟环境在 `.runtime/`，首次准备可能另有 `.python/`；复用的完整 Python 环境也支持位于 `runtime/`。
- 本机整合后，可把源码仓库、运行环境和下载缓存统一放在一个程序根目录；没有必要保留第二个活动程序目录。
- 仅存在于本机的 `.local/install.json` 使用相对程序根目录的路径，也兼容已有外部绝对路径，不依赖当前工作目录。
- 旧脚本与迁移前入口可以隔离在 `.local/` 迁移备份中，不作为活动入口，不进入发布包。
- Windows 用户偏好独立保存在 `%APPDATA%\QwenOfflineReader`，不随源码更新覆盖。
- 用户主动导出的 MP3 保存在用户选定目录，不列入发布清单。

同一程序根目录下，各部分仍有清楚边界：`app/` 是活动程序，`runtime/` 或 `.runtime/` 是环境，`.downloads/` 是可复用下载文件，`.local/` 是本机配置与维护资料。整合时应验证内容、修正环境入口和快捷方式，不重新下载已经完整的文件。完整 Python 环境与虚拟环境均不能未经验证就宣称可任意移动。

## 待发布文件

`scripts/build_release.py` 从允许的目录、类型与固定名称收集文件，检查目录越界和常见敏感信息，再输出到 `dist/`。

模型、安装包、运行环境、个人配置、生成音频、日志、下载记录和缓存不进入源码 ZIP。测试和文档属于维护内容，普通用户不需要手动执行。发布包与本机完整工作目录不是同一个集合。

本地构建不创建远程仓库、不上传文件、不触发远端工作流。
