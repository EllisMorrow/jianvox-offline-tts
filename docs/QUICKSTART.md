# 新手指南：在 Windows 上安装和使用聆笺 JianVox

[返回 README](../README.md)

本文适合第一次使用的人，按 **v0.7.3** 编写。请从发布页下载对应的源码包；托盘关闭开关、直接取字备用通道和取字来源提示从此版本提供。

## 1. 准备电脑和空间

- Windows 10 / 11 的 **64 位 x64 电脑**，以及支持 BF16 的 NVIDIA 显卡。建议 **12 GB 显存、16 GB 以上内存**；实测是 RTX 3060 12GB、32GB 内存。
- 给程序、模型、下载文件和运行环境预留 **25 GB** 可用空间。暂不提供 CPU、AMD 或 Mac 适配。
- 安装兼容 PyTorch CUDA 12.8 的 NVIDIA 显卡驱动；驱动由你自行管理，助手不会代装。
- 准备可用的扬声器或耳机。首次安装会检查音频输出设备。
- 首次需要约 **8.05 GB** 下载（其中模型约 4.52 GB），建议使用稳定网络。下载和安装完成后，日常朗读与 MP3 导出可离线使用。

**运行需要 64 位 Python 3.12，但不用提前手动安装，也不用学习命令行。** 首次脚本会自动处理：

| 电脑上的 Python 情况 | 脚本会做什么 |
| --- | --- |
| 已有兼容的 64 位 Python 3.12 | 用它创建本程序的独立运行环境，不把依赖装进你的原有环境 |
| 没有 Python，或只有不兼容版本 | 先下载约 26 MB 的 Python 3.12.10 安装器，安装到程序目录内，再创建独立运行环境 |

新准备的 Python 位于程序目录的 `.python/`，独立运行环境位于 `.runtime/`；无需手动打开这些目录。不修改全局 PATH、默认 Python 或显卡驱动。这个准备过程发生在模型下载器出现之前，首次可能需要先等待脚本窗口完成工作。

## 2. 下载正确的 ZIP，并完整解压

1. 打开 [JianVox Releases 发布页](https://github.com/EllisMorrow/jianvox-offline-tts/releases/latest)。
2. 找到该版本下方 **Assets（发布附件）**，下载名字为 **`JianVox-v<版本>-windows-source.zip`** 的文件。`<版本>` 以页面显示为准。
3. 不要使用 GitHub 绿色 **Code → Download ZIP**，也不要选 Assets 中 GitHub 自动生成的 `Source code (zip)` / `Source code (tar.gz)`。
4. 在文件资源管理器中右键下载的 ZIP，选择“全部解压”。选择长期保留且可写入的本地目录，例如 `D:\JianVox`；没有 D 盘可选用户目录下的专用文件夹。避免需要管理员权限的系统目录。
5. 打开解压后的文件夹，确认能看到 **`开始下载.cmd`**、**`启动朗读助手.cmd`**、`app` 和 `scripts`。如果外面还有一层同名文件夹，进入包含这些文件的那一层。

不要在 ZIP 浏览窗口中直接运行脚本，也不要只拖出一个 `.cmd` 文件运行。桌面快捷方式依赖整个程序文件夹，安装后请保留原目录。

## 3. 首次双击“开始下载.cmd”

1. 连接网络，双击 **`开始下载.cmd`**。它会先检查系统组件、准备私有环境，然后打开下载器。首次准备 Python 时可能暂时只看到脚本窗口，请等候或查看其中的提示。
2. 下载器自动开始下载，显示总进度、当前文件、速度和预计剩余时间。校验大文件时进度可能暂时不动。
3. 需要暂停时点 **“暂停下载”**；恢复时点 **“继续下载 / 重试”**。关闭下载器也会保留进度，之后从原文件夹重新运行 `开始下载.cmd` 即可。
4. 等待显示 **“全部下载完成，并通过完整性校验”**。完成提示框点“确定”后，**再关闭下载器主窗口**。
5. **保留后方脚本窗口，等它继续工作。** 它会重新核对文件、从本地安装依赖、检查显卡与声音设备、建立“聆笺 JianVox”桌面快捷方式，然后自动启动助手。此阶段不需要手动运行其他安装程序。
6. 助手出现后，等待模型加载与预热；实测约半分钟。看到 **“已就绪”** 后即可朗读。

这里关闭的是**已完成下载的下载器窗口**，不是下载到一半时关闭整个安装脚本。未完成下载时关闭下载器会结束这轮准备，不会继续安装；文件会保留供下次续传。

这是自动配置型源码包，ZIP 本身不包含模型和完整运行环境。不要在另一台电脑上只复制快捷方式使用；另一台电脑应重新按本指南准备。全新电脑完整安装流程尚未在第二台机器实测。

## 4. 以后每天怎么用

以后双击桌面 **“聆笺 JianVox”**，或原文件夹中的 **`启动朗读助手.cmd`**。不需要每天运行“开始下载”，也不必每天联网。每次真正退出后重新打开，模型仍需要加载。

### 第一次试读

1. 等状态显示“已就绪”。
2. 在“朗读”页的正文框粘贴一两句话，例如“你好，这是一次离线朗读测试。”。
3. 点击 **“朗读文字”**。按 **F7** 暂停或继续，按 **F6** 停止。
4. 在网页或文档中选中一段可复制文字，按 **F4** 测试选字朗读。

| 默认操作 | 快捷键 / 按钮 |
| --- | --- |
| 朗读当前选区 | F4 |
| 停止朗读 | F6 |
| 暂停 / 继续播放 | F7 |
| 朗读自己粘贴的文章 | “朗读文字” |
| 朗读已复制的内容 | “朗读剪贴板” |

快捷键可在“快捷键”页修改并保存，留空可停用该项。如果按键被其他软件占用，可换键；也可启用“优先接管已占用快捷键”，该组合将优先由助手处理，退出后释放。系统保留按键、权限差异和其他拦截工具仍可能限制使用。

### 取字来源是什么意思

状态栏提示的是本次任务从哪里拿到文字：

- **剪贴板（主通道）**：选字后通过复制取得文字，这是默认主通道；手动点击“朗读剪贴板”也使用剪贴板。
- **直接取字（备用）**：复制未成功时，尝试 Windows UI Automation（UIA）读取目标软件的真实选区，作为备用通道。
- **窗口文字**：从助手正文框提交朗读任务。

直接取字需要目标软件支持对应的选区接口，不保证任何窗口都能读取；它不识别图片或扫描件，也不能越过 Windows 权限限制。无法读取时，请先在目标软件手动复制，再点“朗读剪贴板”，或粘贴到正文框。失败时不会把旧剪贴板当成新选区朗读。

### 关闭窗口、托盘与真正退出

“设置”中提供 **“点击关闭按钮后进入系统托盘”**，默认开启：点右上角 **×** 后只隐藏窗口，任务、快捷键和正文仍保留。可从任务栏通知区域的托盘图标（可能在隐藏图标箭头中）打开窗口。

关闭此开关后，点 **×** 会停止任务、清空窗口正文并退出；也可直接使用侧栏“退出程序”或托盘退出。开机启动是另一项开关，默认关闭；开启后下次登录只进入托盘。

正文不会写入历史或设置文件，**真正退出后不能恢复**；想保存朗读内容，请自行保存原文，或明确导出 MP3。主题、声音、语气、快捷键、语速、音量、导出方式及常用目录等偏好会自动保留。

## 5. 导出一份 MP3

1. 在正文框粘贴文章，先用短文确认声音、语气、语速和音量。
2. 可点 **“导出MP3时间预估”**。首次会生成短样本进行测量，不播放、不保存；结果只是参考范围。
3. 选择 **“单个 MP3”** 或 **“分章 MP3”**，点击 **“导出 MP3”**，选择保存位置和文件名。
4. 等待完成。需要取消时点“停止”；F7 暂停键用于朗读播放，不用于暂停导出。

单个 MP3 要全部成功才保存，失败或取消后需重做。分章模式约 3000 字一个文件，按 `_001.mp3`、`_002.mp3` 编号，不会识别原文章节；已经完成的章会保留，没有自动续作功能。不会覆盖已有同名文件。

普通朗读最多 20000 字，导出输入最多 100 万字；百万字是输入容量上限，尚未完成百万字全程实测。长文建议先导出一章确认效果。

音量 100% 为原始音量，100–150% 为增强范围，150% 最高约 +9 dB，并柔和限制高峰；不保证完全无失真。导出中调音量只影响后续片段，整份一致请在开始前设定。导出期间不能同时用同一个模型朗读其他文字，需先停止导出。

完整的预估误差、临时文件及异常保存规则见 [README 的 MP3 导出说明](../README.md)。

## 6. 常见问题

| 现象 / 提示 | 怎么处理 |
| --- | --- |
| 缺少 Microsoft Visual C++ x64 runtime | 从 [微软官方 x64 运行库链接](https://aka.ms/vc14/vc_redist.x64.exe) 安装，按安装器提示完成后，重新双击“开始下载”。助手不会静默代装系统运行库。 |
| 找不到 NVIDIA / CUDA unavailable / BF16 提示 | 核对 NVIDIA 显卡型号和驱动，安装或更新兼容 CUDA 12.8 的官方驱动后重试。只有 CPU 或 AMD 显卡的电脑不在当前支持范围内。 |
| 磁盘剩余空间不足 | 检查程序所在磁盘可用空间，按提示留足空间，建议预留 25 GB。保留原下载目录，再重试。不要删除下载断点来“修复”下载。 |
| 下载慢、超时或中断 | 检查网络，点“继续下载 / 重试”；窗口已关闭则从原文件夹重新双击“开始下载”。已完成文件会核验复用，未完成文件可续传。 |
| 下载已经 100%，却还没安装 | 先确认完成提示，然后关闭下载器主窗口，保留后方脚本窗口等安装完成。 |
| 提示 No audio output device | 连接或启用扬声器 / 耳机，确认 Windows 能识别输出设备，再重新准备。 |
| 打开助手后暂时不能朗读 | 等模型加载至“已就绪”；实测约半分钟。若失败，查看错误提示，停止任务后可在设置点“重新加载声音”。 |
| 选中文字按 F4 没反应 | 先确认助手已就绪和快捷键已保存；试在正文框朗读，再试手动复制后“朗读剪贴板”。某些受保护内容或软件不支持自动取字，管理员权限窗口也可能受限。 |
| 按 × 后仍在后台 | 默认进入托盘。要完全关闭，使用“退出程序”，或在设置关闭“点击关闭按钮后进入系统托盘”。 |
| 删除 / 移动文件夹后快捷方式失效 | 快捷方式依赖原目录。不要随意搬动已配置的环境；迁移需核对环境和路径，另一设备应重新准备。 |

脚本报错时请保留错误提示，不要仅凭黑色窗口关闭就判断安装成功。需要反馈时可在设置点“复制诊断摘要”，提供系统版本、显卡型号、必要复现步骤和脱敏提示；不要上传个人正文、音频或设置文件。

## 7. 数据、更新与使用边界

- 应用自身不保存正文、朗读历史或使用统计。普通朗读在内存中处理；导出只保留你明确保存的 MP3，常规取消或失败会清理临时音频。
- 通过剪贴板取得文字时，在朗读任务接受后才清理本次文本；失败或尚未就绪时保留，后来复制的新内容不会被清除。直接取字通道不读取、改写或清理剪贴板。Windows 剪贴板历史、云同步、其他软件副本、系统备份等不受助手控制，不等于整台电脑“完全无痕”。
- 偏好存于 `%APPDATA%\QwenOfflineReader\settings.json`，设置页可打开文件夹。目录名为兼容旧版保留，更新或删除程序目录不会自动删除偏好。
- 不自动更新。更新前先真正退出，并保存需要保留的正文。不要删除旧目录和环境后才尝试新版；发布包不含已下载的模型与环境，复用或迁移这些文件属于高级操作，见 README 的本地目录说明及对应版本发布说明。
- 不要把“模型能生成声音”理解为读音完全正确。数字、多音字、英文、专有名词可能读错；分段可能停顿，显卡繁忙时可能等待。重要内容请核对。
- 默认音频设备切换会尝试重连；设备断开超过约 15 秒会停止本次播放，恢复后可重新朗读。无播放设备时，已经配置完成的程序仍可导出 MP3。
